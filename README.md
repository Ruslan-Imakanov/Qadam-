# Qadam — сайт агентства недвижимости и оценки

Сайт полного цикла для агентства в Казахстане: купля-продажа и аренда, коммерческая недвижимость,
юридическое сопровождение, ипотечный брокер и **оценка движимого и недвижимого имущества**.
Плюс админка (CRM) для заявок, заказов на оценку, объектов и всего контента.

Стек как у «Табеля»: Supabase (Postgres + Auth + RLS + Storage) и статические HTML/CSS/JS без сборки.
Хостинг — Cloudflare Pages (подойдёт любой статический).

## Что собрано в базе

Наполнение — `tools/content.mjs` (источник), из него `tools/build-seed.mjs` генерирует `supabase/seed.sql`
и `public/data/demo.json`. Данные на октябрь 2026, по открытым источникам (krisha.kz, finance.kz,
finratings.kz, inform.kz, zakon.kz, tengrinews.kz, kapital.kz, nur.kz):

- 18 городов, 20 районов с поправками, средние цены м² (продажа — krisha.kz, май 2026; аренда, дома, земля, коммерция — ориентиры);
- 41 коэффициент онлайн-оценки (материал, состояние, этаж, год, комнатность, коммуникации, износ авто и оборудования);
- тарифы 2026: МРП 4 325 ₸, нотариус 12 / 7 / 17 МРП, согласие супруга 1,5 МРП, госпошлина 1 304 ₸, ИПН 10% / 15% с порогом 8 500 МРП, сроки владения 1 / 2 года;
- 8 ипотечных программ («Наурыз», «Наурыз жұмыскер», «Наурыз Әскери», «Отау», «Свой дом», «7-20-25», «Ұмай», рыночная);
- 21 услуга, 16 видов оценки, 12 целей оценки, 31 этап работы, 13 чек-листов, 24 FAQ, 39 терминов, 12 статей;
- 14 демо-объектов и 4 демо-сотрудника (помечены «демо», удаляются одной кнопкой в админке).

> Цены, ставки и тарифы меняются. Всё редактируется в админке: «Цены и коэффициенты», «Контент сайта», «Настройки».

## Запуск

### 1. База (Supabase)

Проект в Supabase: **realty-agency** (`feuqorxannlztgxgdwyz`, Франкфурт, бесплатный тариф).

1. Supabase → SQL Editor → выполнить `supabase/schema.sql` (таблицы, RLS, триггеры, бакеты Storage).
2. Там же выполнить `supabase/seed.sql` (наполнение). Повторный запуск безопасен — существующие строки не перезаписываются.
3. Authentication → URL Configuration: в **Site URL** и **Redirect URLs** указать адрес сайта
   (например `https://имя-сайта.pages.dev/admin.html`) — иначе ссылки из писем (подтверждение, сброс пароля) поведут на localhost.

### 2. Подключение сайта к базе

В `public/config.js` вписать Project URL и **publishable/anon** ключ (Project Settings → API).
Пока поля пустые, сайт работает в **демо-режиме** на `data/demo.json`: всё кликается, заявки и правки
сохраняются только в браузере.

### 3. Хостинг (Cloudflare)

Сайт опубликован: **https://qadam-realty.imakanovr.workers.dev** — Cloudflare Worker `qadam-realty`
со статическими файлами из `public/` (код воркера — `worker.js`, заголовки — `public/_headers`).
Отдельный сайт, к «Табелю» не относится.

Обновление (так делает Claude через коннектор Cloudflare; вручную — те же запросы через curl с API-токеном):
1. `node tools/cf-deploy.mjs manifest public` → POST `/accounts/{id}/workers/scripts/qadam-realty/assets-upload-session`.
2. `node tools/cf-deploy.mjs upload public <jwt-файл> '<buckets>'` — загружает только изменившиеся файлы.
3. PUT `/accounts/{id}/workers/scripts/qadam-realty` (multipart: metadata + `worker.js`) с полученным jwt,
   `compatibility_flags: ["assets_navigation_has_no_effect"]` и
   `assets.config = { html_handling: "none", not_found_handling: "404-page", _headers: <содержимое public/_headers> }`.
   Без этого флага браузер на «/» и коротких адресах получает 404.html (Cloudflare не вызывает воркер для переходов).

Локально: `cd realty/public && python3 -m http.server 8080` → http://localhost:8080.

### 4. Первый вход

`admin.html` → «Создать администратора» — первый зарегистрированный аккаунт автоматически становится
администратором. Следующие сотрудники регистрируются там же и получают роль «нет доступа»,
пока вы не назначите им «агента» или «администратора» в разделе «Пользователи».

### 5. Перед запуском (чек-лист есть на «Обзоре» админки)

- Настройки → телефон, WhatsApp, адрес, координаты офиса, юр. название и БИН.
- Настройки → Telegram: токен бота и chat_id — каждая заявка и заказ на оценку будут приходить в Telegram (через `pg_net` прямо из базы).
- Объекты → «Удалить демо-объекты», добавить свои с фото.
- Команда → заменить демо-сотрудников, указать квалификационные свидетельства оценщиков.
- Цены и коэффициенты → сверить цены м² по своим городам.
- `privacy.html` — проверить текст политики с юристом.

## Доступ и безопасность

- Посетитель (anon) читает только опубликованное и может **только отправить** заявку, заказ на оценку, отзыв и файлы — прочитать чужие заявки нельзя (RLS).
- Агент — объекты, заявки, оценка. Администратор — ещё контент, цены, команда, настройки, роли.
- Телефон собственника, комиссия и заметки по объекту — в отдельной закрытой таблице `listing_private`.
- Фото объектов — публичный бакет `photos`; фото и документы от посетителей — закрытый бакет `incoming` (видят только сотрудники).
- Токен Telegram — в `private_settings`, читает только администратор.
